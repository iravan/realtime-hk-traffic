# Realtime HK Traffic — 功能列表

為所有在香港出行的人而設。

## 一按即看實時到站
- 港鐵每條綫的下班車時間，並顯示綫路服務狀態。
- 輕鐵（Light Rail）到站時間。
- 九巴、龍運、城巴及新大嶼山巴士的路線與到站時間。
- 綠色專線小巴的到站時間（官方有提供預報者）。
- 天星小輪及新渡輪的班次與開船時間。
- 的士站位置。

## 快速地圖
- 所有站點以圖釘顯示於 OpenStreetMap 底圖，毋須登入。
- 拖動地圖不會向伺服器請求站點。
- 縮放較低時站點會合併為數字氣泡，點擊即可放大。

## 站點詳情
- 站名以英文或繁體中文顯示。
- 以彩色標籤顯示所有服務路線。
- 港鐵站設施：洗手間、飲水機、育嬰室、Wi-Fi。
- 渡輪班次表及目的地。
- 已公布的服務時間。

## 為香港而設
- 雙語介面（English / 繁體中文）。
- 位置感知：開啟時自動定位最近的站點。
- 每個分頁記住上次開啟的站點。
- 可分享站點連結。
- 支援 iOS 及 Android 加到主畫面（PWA）。
- 無廣告、無帳號、完全免費。
